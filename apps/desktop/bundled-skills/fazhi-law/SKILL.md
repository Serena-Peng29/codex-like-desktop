## 可用工具

本技能提供**三个固定接口**，无需工具发现，根据需求直接选择调用：

| 接口（接口ID） | 功能 | 方法 | 路径 | 参数 |
|---|---|---|---|---|
| `search_article`  | 语义检索法律法规 | GET | `/v1/mcp/law_search/search_article` | `query`（必填） |

**接口选择规则**：

| 用户意图 | 调用接口 | 参数 |

| 用自然语言找相关法条 | `search_article` | `query` |

## 智能迭代搜索

### 迭代触发条件

当出现以下情况时，自动启动迭代搜索：

- **结果数量不足**：返回结果少于 3 条
- **结果相关性低**：返回结果与用户意图不符
- **关键词模糊**：关键词过于宽泛或专业
- **复杂查询**：涉及多个法律概念
- **结果不完整**：缺少关键信息或细节

### 迭代优化策略

| 策略         | 适用场景   | 优化方法           |
|------------|--------|----------------|
| **关键词扩展**  | 关键词过精确 | 添加同义词、上位概念     |
| **关键词简化**  | 关键词过具体 | 移除修饰词，保留核心概念   |
| **多维度搜索**  | 多法律概念  | 拆分为多个关键词分别搜索   |
| **法律层级扩展** | 未找到条文  | 扩展到司法解释、部门规章   |
| **案例关联检索** | 需要更多案例 | 从案例标题提取关键词关联搜索 |

### 迭代终止条件

- 迭代次数达到 3 次
- 找到 10 条以上相关结果
- 找到足够覆盖用户需求的结果
- 连续两次迭代结果无显著变化

### 迭代结果说明

当执行迭代搜索时，应说明：

```markdown
🔍 搜索过程说明：

本次查询进行了智能迭代优化：

- 初步查询：[关键词1] - 返回 X 条结果
- 优化查询：[关键词2] - 返回 Y 条结果
- 最终呈现：精选 Z 条最相关结果
```

## 各接口返回字段说明

### `search_article`（语义检索法律法规）返回

每条法规包含：`id`、`title`（标题）、`number`（条号）、`content`（内容）、
`effectiveness`（效力级别）、`pub_date`（发布日期）、`effect_date`（生效日期）、
`status`（时效性：现行有效/已被修改/失效/部分失效/尚未生效）。

### `get_article`（精确获取法条）返回

根据 `title`（法律名称）+ `number`（条号）精确返回目标法条，字段同上。

### `search_case`（语义检索司法案例）返回

每个案例包含：`id`、`title`（标题）、`case_no`（案号）、`content`（内容）、
`doc_type`（文书类型，如判决书）、`court`（审理法院）、`judge`（判决/本院认为）、
`judge_date`（判决日期）。

### 3. 类案检索

#### 工作流程

1. **深度案情分析**：识别案件类型、提取案情特征（主体、行为、结果、争议焦点等）。
2. **精准关键词提取与迭代**：提取核心关键词 + 扩展关键词，进行多轮迭代优化。
3. **全面案例检索**：调用 `search_case`，优先筛选与案情接近的判例，输出多个相似案例。
4. **结构化相似度评估**：按案件类型、核心事实、争议焦点、裁判结果逐维度打分对比。
5. **生成详尽输出**：案情画像、检索概述、相似案例详解、综合建议。
6. **溯源展示**：📚 参考文献展示所有引用案例。

#### 示例

**用户**：找类似的交通事故赔偿案例

**AI 处理**：
1. 构建案情画像（交通事故 + 赔偿）
2. 提取关键词：交通事故、赔偿、责任
3. 调用 `search_case` 检索 + 筛选
4. 逐案结构化相似度评估
5. 生成详尽回复，📚 展示所有引用案例

### 4. 法条检索

#### 工作流程

1. **深度识别检索需求**：判断法律层级、范围（现行有效、失效等），提取核心关键词。
2. **全面精准检索**：优先用 `get_article` 精确查询，不确定条号时用 `search_article` 语义定位。
3. **条文体系化整理**：按效力状态分类，标注条文全文、效力级别、适用说明。
4. **生成详尽解读**：法条原文 + 逐条拆解 + 适用场景 + 关联条文。
5. **溯源展示**：📚 展示所有引用法条。

| 只知领域不知条号 | `search_article` | `query`=领域关键词 |

以下地址获取：

```
https://open.kuaicha365.com/lawskills/
```

**注意**：

  终端执行任何命令。
- 若用户询问如何获取，引导其打开上述网址注册并生成 API Key。
- 若 Key 无效或失效，提醒用户重新前往上述地址生成新 Key 后再次提供。

### 保存与复用

- AI 拿到用户提供的 Key 后，通过以下命令**自动写入** `~/.fazhi/config` 保存
  （由 AI 执行，不让用户手动操作）：

  ```bash
  node <skill_dir>/scripts/fazhi_tool.mjs set-key "<api-key>"
  ```

- 之后的调用会自动从 `~/.fazhi/config` 读取 Key，无需用户再次提供。
  只有 Key 失效、或用户要求更换时，AI 才需再次向用户索取并重新写入。

### 认证要求

- Key 由调用方注入 `open-authorization` 请求头，AI 不应在对话中明文展示完整 Key。
- 不在检索参数中包含业务无关的个人敏感信息。
