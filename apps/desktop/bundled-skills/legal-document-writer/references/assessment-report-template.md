## 二、风险指数与等级

**评分区间（100 分制）**，数值越高风险越高：

| 区间 | 风险等级 |
| --- | --- |
| 75 – 100 | 重大风险 |
| 50 – 74 | 中等风险 |
| 25 – 49 | 一般风险 |
| 0 – 24 | 较低风险 |

**风险指数说明**（固定句式，可保留原文）：
> 指数最高分为 100 分，数值越高说明风险越高，具体分为：重大风险（75–100）、中等风险（50–74）、一般风险（25–49）、较低风险（0–24）。

**指数判定依据**：结合案由胜诉概率、证据充分度、时效风险、执行风险、程序障碍等因素综合打分，并在「（一）分析建议」中说明打分理由。

## 三、各章节撰写要点

### （一）分析建议
- 先点明该案由的核心法律要件（如离婚案为「夫妻感情确已破裂」）。
- 结合用户选择/提供的具体情形，判断是否满足法定条件（如存在「与他人同居」「家庭暴力」等法定情形）。
- 客观提示败诉风险：起诉不符合条件、超过诉讼时效、证据不足、一方下落不明、执行不能等。

### （二）个人信誉
- 说明当事人享有的诉权（起诉、撤诉、上诉）。
- 提示虚假诉讼、恶意诉讼的法律风险与信誉损害。

### 二、行动建议
按「协商沟通 → 人民调解 → 提起诉讼」三步递进给出建议，说明各自的适用条件与成本。

### 三、解决途径
- **调解流程 / 诉讼流程**：分步骤列出（流程步骤可用编号列表；如原文档该处为流程图示，可简化为步骤文字或说明「详见流程图」）。
- **调解所需材料**：列举（人民调解申请书、身份证明、被申请人信息、证据材料等）。
- **诉讼所需证据、材料**：针对具体案由列举证据类型（如离婚案「与他人同居」的证据：证人证言、房东证明、电子邮件/短信/微信、报警记录、照片、生育情况等）。
- **调解与诉讼对比**：用表格呈现对比维度——自愿性、和解性、保密性、经济成本。

### 四、时间成本
- 给出该案由从申请到结案的预计耗时（如调解约 15 天）。
- 列出不计入审限的情形：公告期间、鉴定期间、处理管辖问题期间。

### 五、经济成本
- **（一）诉讼费**：案件受理费标准（按标的额分段），如离婚案 50–300 元；涉及财产分割按 0.5% 等。
- **（二）其他费用**：鉴定费、申请执行费、上诉费等，分段给出收取标准。

### 六、法律法规
- 引用与案由直接相关的法条全文（如《中华人民共和国民法典》第一千零七十九条等）。
- 法条引用完整、准确，标注条文序号。

### 温馨提示（固定 4 条）
1. 详细评估结果必要时请咨询法律专业人员；
2. 评估结果仅针对您此次提供的案情信息；
3. 任何评估系统都无法覆盖所有风险，诉讼请谨慎；
4. 本评估结果仅供您参考，并不代表本院裁判观点。

---

## 四、撰写原则

1. **客观中立**：不夸大胜诉把握，如实披露风险。
2. **紧扣案情**：所有建议、证据清单、费用标准均基于用户提供的具体案情与案由。
3. **量化可执行**：费用、时间、评分尽量给出具体数字或区间。
4. **免责声明**：末尾务必保留「温馨提示」免责内容。
5. **日期**：告知日期使用生成当日日期。
