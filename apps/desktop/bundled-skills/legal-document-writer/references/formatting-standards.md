# 中国法律文书排版格式规范

> 本文件定义生成法律文书 Word 文档时统一遵循的排版标准。生成脚本 `scripts/generate_legal_doc.py` 已按此规范内置默认值；用户/招标方另有格式要求时，以用户明确要求为最高优先级。

## 一、页面设置（依据 GB/T 9704-2012 党政机关公文格式）

| 项目 | 取值 |
| --- | --- |
| 纸张 | A4（210mm × 297mm） |
| 上边距 | 37mm（3.7cm） |
| 下边距 | 35mm（3.5cm） |
| 左边距 | 28mm（2.8cm） |
| 右边距 | 26mm（2.6cm） |
| 版心 | 156mm × 225mm |

## 二、字体与字号

| 层级 | 字体（中文字体） | 字号 | 是否加粗 | 对齐 |
| --- | --- | --- | --- | --- |
| 文书标题（如「民事起诉状」） | 宋体（可用方正小标宋） | 二号（22pt） | 加粗 | 居中 |
| 副题 / 案号 | 仿宋_GB2312 | 三号（16pt） | 否 | 居中 |
| 正文 | 仿宋_GB2312 | 三号（16pt） | 否 | 两端对齐 |
| 一级标题（一、） | 黑体 | 三号（16pt） | 是 | 左对齐 |
| 二级标题（（一）） | 楷体 | 三号（16pt） | 否 | 左对齐 |
| 三级标题（1.） | 仿宋_GB2312 | 三号（16pt） | 是 | 左对齐 |
| 落款 / 署名 | 仿宋_GB2312 | 三号（16pt） | 否 | 右对齐 |

数字、字母、标点中的西文部分统一使用 Times New Roman。

## 三、段落与行距

- 正文行距：固定值 28 磅。
- 正文首行缩进：2 字符（即字号 × 2，三号正文为 32pt）。
- 标题与正文之间适当留白（段前 6pt 左右），落款与正文之间留白。

## 四、字号可选档位

诉讼实务中「三号（16pt）」为公文标准；若用户偏好紧凑排版，可选用以下档位（通过 spec 的 `font_size` 字段调整）：

| 档位 | 正文字号 | 适用场景 |
| --- | --- | --- |
| 三号 | 16pt | 公文式文书、判决书、调解书（默认） |
| 四号 | 14pt | 一般起诉状、答辩状 |
| 小四 | 12pt | 篇幅较长、需压缩页数的材料 |

## 五、落款与日期规范

- 起诉状 / 答辩状落款：右对齐，一般写「具状人（答辩人）：×××」与成文日期。
- 判决书 / 调解书落款：写法院名称、合议庭（审判员）、书记员、日期，并加盖院印位置。
- 日期使用中文数字（如「二〇二六年九月二日」）或阿拉伯数字（如「2026年9月2日」）均可，但同一文书内应保持一致；公文规范倾向中文大写日期。

## 六、其他注意事项

1. 全角标点、半角数字混排时，数字与英文字母用 Times New Roman。
2. 文中引用法条时，法律名称使用书名号，如《中华人民共和国民法典》。
3. 避免使用 emoji 与花哨装饰，保持庄重、规范的公文风格。
4. 涉及当事人身份证号、住址、联系方式等敏感信息时，注意脱敏处理。
