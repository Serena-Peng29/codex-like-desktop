# Phase 0 技术验证

## 目标

验证用户只安装产品客户端即可完成一次完整的本地 Agent 任务和服务端测试扣费。

## 验收项

- 启动桌面客户端后自动启动随包 App Server。
- 用户选择本地项目目录。
- 客户端通过 App Server 完成一次 GPT 流式对话。
- AI 生成文件差异并在用户确认后写入。
- 命令执行前出现审批，命令在本机执行。
- 后端网关记录请求和 token 用量。
- 套餐额度优先抵扣，余额不足时拒绝请求。
- 客户端展示本次费用和最新余额。
- 关闭客户端后可以清理或恢复 App Server 进程。

## 暂不接入

- 微信支付正式回调。
- 支付宝正式回调。
- 团队账户。
- 远程沙箱。
- 多模型路由。
