# Codex 上游同步策略

## 同步范围

只同步公开的 Codex CLI、SDK、App Server 和协议源码，不包含官方闭源桌面客户端或官方内部服务。

## 推荐流程

1. 在 `vendor/codex` 固定上游 commit、tag 或 release。
2. 通过 CI 定期检查上游变化。
3. 编译 Windows 和 macOS App Server sidecar。
4. 运行协议、流式输出、文件修改、命令审批和计费链路测试。
5. 通过测试后生成产品自己的版本。
6. 对安装包和更新包进行代码签名。
7. 灰度发布，失败时回滚上一版本。

## 版本记录

每个产品版本必须记录：

- 上游 Codex 版本或 commit。
- 产品自己的修改。
- 协议 Schema 版本。
- 已知兼容性问题。
- 是否需要迁移本地配置或历史数据。
